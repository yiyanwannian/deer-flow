# DeerFlow 快速上手指南

## 项目核心理解

### 什么是DeerFlow？
DeerFlow是一个**智能研究助手**，它能够：
- 📚 **自动分解复杂查询** - 将"研究量子计算对密码学的影响"分解为多个可执行步骤
- 🔍 **多源信息收集** - 同时使用网络搜索、学术论文、网页爬取等方式收集信息
- 🤖 **智能体协作** - 研究员负责信息收集，编码员负责数据分析和计算
- 📝 **自动报告生成** - 将收集的信息整合成结构化的研究报告

### 核心工作原理
```
用户查询 → 智能规划 → 多智能体执行 → 信息整合 → 生成报告
```

## 快速启动

### 1. 环境准备
```bash
# 克隆项目
git clone https://github.com/bytedance/deer-flow.git
cd deer-flow

# 安装依赖（uv会自动管理Python环境）
uv sync

# 配置环境变量
cp .env.example .env
cp conf.yaml.example conf.yaml
```

### 2. 基础配置

#### .env文件配置（必需）
```bash
# 搜索引擎配置（选择一个）
SEARCH_API=tavily
TAVILY_API_KEY=your_tavily_key

# 或者使用免费的DuckDuckGo
SEARCH_API=duckduckgo

# LangSmith追踪（可选）
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=your_langsmith_key
```

#### conf.yaml文件配置（必需）
```yaml
BASIC_MODEL:
  model: "gpt-4o-mini"  # 或其他OpenAI兼容模型
  api_key: "your_openai_key"
  base_url: "https://api.openai.com/v1"  # 或其他兼容端点

REASONING_MODEL:
  model: "gpt-4o"
  api_key: "your_openai_key"
  base_url: "https://api.openai.com/v1"
```

### 3. 第一次运行

#### 命令行模式
```bash
# 直接提问
uv run main.py "什么是大语言模型？"

# 交互式模式
uv run main.py --interactive

# 调试模式
uv run main.py --debug "分析比特币价格波动"
```

#### Web UI模式
```bash
# 启动开发服务器
./bootstrap.sh -d

# 访问 http://localhost:3000
```

## 核心功能演示

### 1. 基础研究查询
```bash
uv run main.py "分析人工智能在医疗领域的应用现状"
```

**系统会自动：**
1. 生成研究计划（如：AI技术概述、医疗应用案例、挑战分析）
2. 执行网络搜索收集信息
3. 分析和整合数据
4. 生成结构化报告

### 2. 技术分析查询
```bash
uv run main.py "比较不同排序算法的时间复杂度"
```

**系统会自动：**
1. 编写Python代码实现各种排序算法
2. 进行性能测试和分析
3. 生成可视化图表
4. 输出详细的技术报告

### 3. 数据分析查询
```bash
uv run main.py "分析最近一年的股市趋势"
```

**系统会自动：**
1. 搜索相关的市场数据
2. 使用Python进行数据处理和分析
3. 生成趋势图和统计分析
4. 提供投资建议和风险评估
